### ⚠️ Gemini API Anahtarı Bulunamadı

Tarih: 2026-10-20 14:40:41 UTC

Gemini'nin commitlerinize otomatik yanıt verebilmesi için GitHub Secret eklemeniz gerekmektedir:

1. GitHub repo sayfanızda **Settings** > **Secrets and variables** > **Actions** bölümüne gidin.
2. **New repository secret** butonuna tıklayın.
3. Name: `GEMINI_API_KEY`
4. Secret: [Google AI Studio](https://aistudio.google.com/app/apikey) adresinden aldığınız Gemini API anahtarını yapıştırın.
5. **Add secret** ile kaydedin ve tekrar bir commit atın!
