# 📱 Mobil Uygulama Geliştirme Notları & Gemini İstekleri

Buraya mobil uygulamanızla (Flutter, React Native, Swift, Kotlin vb.) ilgili sorularınızı, geliştirmek istediğiniz özellikleri veya inceletmek istediğiniz kod bloklarını yazabilirsiniz.

Her commit attığınızda (veya bu dosyayı güncelleyip commit ettiğinizde):
1. GitHub Actions otomatik çalışır.
2. Commit mesajınız, değişiklikleriniz ve bu dosyadaki içerik Gemini'ye iletilir.
3. Gemini'nin ürettiği yanıt otomatik olarak `response.md` dosyasına yazılır ve repoya geri commit edilir.
4. Tüm geçmiş diyaloglar ise `chat_history.md` dosyasında birikir.
